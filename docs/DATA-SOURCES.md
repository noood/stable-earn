# 数据源设置

在私人页右上角的更多菜单中打开“数据源设置”。产品信息、APR 和持仓可以来自不同渠道；接入一项数据不代表其他字段也能自动获取。

## 平台与配置方式

| 平台 | 需要配置 | 产品与 APR | 持仓 |
| --- | --- | --- | --- |
| Binance Global / Bahrain | 交易所只读 Key、Secret | API 同步 | API 同步 |
| Bybit Global | 交易所只读 Key、Secret（用于持仓） | 已接入范围使用公开 API | API 同步 |
| Bybit EU | 无需 API Key | 已接入范围使用公开 API | 手动维护 |
| Bitget | 交易所只读 Key、Secret、Passphrase | API 同步 | API 同步 |
| OKX | 交易所只读 Key、Secret、Passphrase | 手动维护 APR、首档额度 | API 同步 USDT、USDC、BTC 活期余额 |
| MEXC PH / UK | 无 | 手动维护 | 手动维护 |
| Bitget Wallet | Morph 链钱包公开地址 | 手动维护整体 APR、首档额度 | 链上同步已支持金库的 USDC 持仓 |

表中“API 同步”表示项目已有接入，不保证每个平台、币种、产品都有完整数据。交易所逐项覆盖、权限和核验依据见[平台 API 能力矩阵](PLATFORM-CAPABILITIES.md)；字段缺失及缓存行为统一见[数据规则](DATA-STATES.md)。

## 配置 API

在对应平台行点击“添加”，填写只读凭证并选择“加密保存”；已配置的平台通过更多菜单更新或移除。Key 必须关闭交易、转账、申购、赎回和提现权限，完整凭证不会返回浏览器，详见[安全策略](../SECURITY.md)。

需要人工维护的资料，在“编辑持仓”中填写；也可通过“添加产品”维护手动产品。

## 钱包地址

在 Bitget Wallet 行点击“添加”，填写实际持有该理财的钱包公开地址并保存，网络由“Morph 链”副标题标明。只需要公开地址，不需要私钥、助记词、签名、交易所 API Key 或 Dune Key。

当前仅支持 Morph（链 ID `2818`）的 Gauntlet USDC 金库：`0x9131eb40bd0bdce73c72755f1bb2cf39a9453341`。同步的是该金库份额对应的当前 USDC 估值，不扫描钱包的全部链上资产。

- 配置钱包后才接入该产品；它不是默认产品。
- 在“编辑持仓”中手动填写整体 APR（含奖励），设置首档额度；持仓由链上同步，保持只读。
- 首档额度使用共用的“限额 / 不限额”菜单；限额需填正数，空白是待填写。应按平台显示的收益适用范围选择，官方申购及奖励上限尚未通过接口验证。
- 更换或移除钱包会清除旧钱包的当前持仓与同步缓存，保留产品资料、手动设置和历史；具体边界见[钱包数据规则](DATA-STATES.md#bitget-wallet--morph)。

链上事实及自动收益率来源的验证依据另存于[调研资料](research/BITGET-WALLET-MORPH-USDC.md)，其中的历史利率不作为当前配置。

## 刷新与接口检查

“手动刷新频率”只限制账号维度的手动刷新间隔，不影响每日首次打开页面的自动刷新。设置会同步到同一邮箱的其他设备。

“API 检测”检查代码已知的交易所接口，并生成报告；它不检查钱包 RPC，也不会自动发现未知接口或更新产品/持仓。排查单个平台或币种时，按[诊断说明](DIAGNOSTICS.md)选择最窄范围。
